맞물린 톱니바퀴는 서로 **반대 방향**으로 돌아요. 일곱 개를 하나씩 따라가 보세요.

## 한 걸음 더: 맞물림 횟수와 방향

톱니바퀴가 한 번 맞물릴 때마다 회전 방향이 바뀌어요. 그래서 맞물림 횟수가 **짝수**면 첫 번째와 마지막 톱니바퀴는 같은 방향으로 돌고, **홀수**면 반대 방향으로 돌아요. 또 톱니 수가 적은 바퀴가 더 빨리 돌아요. 반지름이 절반이면 속도는 두 배예요.

## 코딩으로 해석하기

```python
gears = 7
direction = "시계"
for i in range(1, gears):
    direction = "반시계" if direction == "시계" else "시계"
    print(i + 1, "번째 톱니바퀴:", direction)
```

바퀴 수를 바꿔 보며 마지막 바퀴의 방향이 어떻게 달라지는지 확인해 보세요.
