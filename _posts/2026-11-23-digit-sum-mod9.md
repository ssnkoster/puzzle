## 풀이의 열쇠: 자릿수를 더해 보기

28은 2+8=10, 82는 8+2=10처럼 **각 자리 숫자를 더하면** 같은 값이 나오는 숫자들이 있어요. 이렇게 공통점을 찾을 때는 "크기, 홀짝, 자릿수 합"처럼 숫자를 보는 관점을 하나씩 바꿔 보는 게 요령이에요.

## 한 걸음 더: 자릿수 합은 왜 쓸모가 있을까?

어떤 수의 자릿수 합을 9로 나눈 나머지는 **원래 수를 9로 나눈 나머지와 같아요.** 이유는 간단해요. 10, 100, 1000…은 모두 9로 나누면 나머지가 1이라서, 34 = 3×10 + 4는 9로 나눈 나머지가 3+4와 같거든요.

그래서 자릿수 합이 같은 두 수는 9로 나눈 나머지도 같아요. 이 성질로 **9로 나누어떨어지는지**를 바로 알 수 있어요. 자릿수 합이 9의 배수이면 그 수도 9의 배수예요. (예: 738 → 7+3+8=18 → 738은 9의 배수)

## 코딩으로 해석하기

```python
def digit_sum(n):
    return sum(int(c) for c in str(n))

nums = [28, 82, 19, 37, 55, 64, 38, 73, 91, 46]
print([digit_sum(n) for n in nums])
```

`%`(나머지) 연산으로 `n % 9`와 비교해 보면, 자릿수 합과 9로 나눈 나머지가 늘 짝을 이루는 걸 확인할 수 있어요. 직접 숫자를 바꿔 보며 실험해 보세요!
