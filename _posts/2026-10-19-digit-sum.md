풀이의 열쇠는 숫자를 보는 관점을 바꾸는 거예요. 크기, 홀짝, 그리고 **각 자리 숫자의 합**까지 하나씩 살펴보세요.

## 한 걸음 더: 자릿수 합은 왜 쓸모가 있을까?

어떤 수의 자릿수 합을 9로 나눈 나머지는 **원래 수를 9로 나눈 나머지와 같아요.** 10, 100, 1000…은 모두 9로 나누면 나머지가 1이라서, 34 = 3×10 + 4는 9로 나눈 나머지가 3+4와 같거든요. 그래서 자릿수 합이 9의 배수이면 그 수도 9의 배수예요. (예: 738 → 7+3+8=18 → 9의 배수)

## 코딩으로 해석하기

```python
def digit_sum(n):
    return sum(int(c) for c in str(n))

nums = [28, 82, 19, 37, 55, 64, 38, 73, 91, 46]
print([digit_sum(n) for n in nums])
```

`n % 9`와 `digit_sum(n) % 9`를 비교해 보면 항상 같다는 걸 확인할 수 있어요.
