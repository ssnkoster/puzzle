# 퍼즐 워밍업 (puzzle)
매주 퍼즐 힌트 앱 + 원리 해설 기사. 구조는 mathisto와 동일합니다.
- `_posts/YYYY-MM-DD-slug.md` 기사 (front matter: layout: post, title, date, thumbnail)
- `demos/NNN-이름/index.html` 퍼즐 힌트 앱
- `assets/episodes/NN-이름/` 기사 이미지
배포: `git add . && git commit -m "N화: 제목" && git push` (Settings → Pages → main / root)
